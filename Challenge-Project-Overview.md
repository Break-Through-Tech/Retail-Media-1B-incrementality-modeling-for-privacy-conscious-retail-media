## 🎯 The Challenge

### Project Summary
Retail media advertisers need to know whether assigning customers to an advertising campaign produced additional activity, not merely whether customers who saw an advertisement later visited or purchased. Customers who are already likely to visit can make a campaign appear successful even when the campaign did not change their behavior.

In this project, we assume that SolePeak Footwear runs a digital advertising campaign through MarketBridge Retail Media. Customer records are randomly assigned to a treatment group that is eligible to receive the advertisement or to a control group that is not targeted by the campaign. The project team will use the anonymized Criteo Uplift Prediction Dataset to compare outcomes between these groups.

The primary goal is to build and evaluate uplift models that rank audience records by their estimated incremental visit response. The primary causal question is the intention-to-treat effect of assignment to the advertising treatment group on visit probability, both overall and across ranked audience groups. It is not the causal effect of actually viewing an advertisement. The team must not filter the primary analysis to records where `exposure = 1` because exposure occurs after treatment assignment.

The team will compare uplift modeling approaches with random targeting and conventional response prediction. Visit will be the primary outcome. Conversion will be treated as an optional secondary outcome because it is much less common in the dataset.

The project represents the analytical stage of a fictional privacy-conscious data clean room measurement workflow. We assume that identity matching, consent controls, overlap construction, access rules, and governance have already occurred upstream. The team will not build an identity graph or a production data clean room. The dataset contains no matching identifiers, so it cannot be used to evaluate identity resolution, match quality, consent, or audience overlap. Public conclusions should use aggregate or cohort-level results. Individual model scores should not be described as privacy-safe audience exports.

### Success Criteria
A successful project will deliver:

- A repeatable Python workflow that runs in Google Colab or another free notebook environment
- A clear exploration of the dataset, including the treatment and control groups, missing values, feature quality, visit rates, and the much rarer conversion rates
- Two simple comparison methods, including random audience ranking and a standard model that predicts who is likely to visit
- At least two uplift modeling methods, including a T-learner that builds separate models for the treatment and control groups and a transformed-outcome method that converts the problem into a single prediction task
- An evaluation using data that was not used to train the models
- Easy-to-understand charts showing whether the highest-ranked audience groups produced more estimated incremental visits than random targeting, together with group counts and uncertainty estimates
- A short discussion of what the results mean for privacy-conscious advertising measurement and what the dataset cannot tell us
- Reproducible notebooks, a short model summary, a results report, and a final presentation

Success does not require an uplift model to outperform every comparison method. Finding that the estimated uplift is weak or uncertain can still be a valuable result when the team explains how it reached that conclusion. Close model results should be treated as ties when the available evidence does not support a reliable winner.

### How the Prepared Sample Was Created

The complete source dataset was profiled and processed before the start of the project. The preparation script:

- Scanned the complete source file instead of selecting only the first rows
- Gave every source record the same probability of being selected
- Used random seed `2026` to make the process reproducible
- Created a sample of exactly 1,000,000 records
- Divided the sample into 700,000 training records, 150,000 validation records, and 150,000 test records
- Closely preserved feature means and key treatment and outcome rates from the full dataset
- Kept identical row patterns within the same data split
- Used source row numbers internally to verify sampling and split integrity, then removed them from the public student files
- Read the source in smaller portions so the entire uncompressed file did not need to be loaded into memory at once

Scanning the complete source was necessary because the file is ordered. The first control record does not appear until source row 5,571,800. Selecting only the first million rows would create a treatment-only sample and make treatment and control analysis invalid.

The reproducible preparation script and validation documentation are included in the [`data`](data) folder.

### Important Modeling Rules

- Use `treatment` to define the primary treatment and control comparison
- Do not use `exposure` as an audience feature because exposure occurs after treatment assignment
- Do not filter the primary analysis to records where `exposure = 1`
- Use only `f0` through `f11` to generate model scores
- Use the training data to train models
- Use the validation data to compare approaches and make modeling decisions
- Use the test data only for the final evaluation
- Treat `visit` as the primary outcome

## 🛠️ Suggested Approach

**Primary ML Problem:** Uplift modeling  
**Supporting ML Problems:** Binary classification and regression  
**Primary Outcome:** `visit`  
**Optional Secondary Outcome:** `conversion`  
**Model Features:** `f0` through `f11`  

### Recommended Workflow

1. **Understand the experiment**
   - Compare visit and conversion rates between the treatment and control groups
   - Calculate the overall intention-to-treat effect as treatment visit rate minus control visit rate
   - Confirm that treatment assignment, exposure, and outcomes are used for their intended purposes
   - Do not interpret the primary result as the effect of actual advertising exposure

2. **Explore the data**
   - Review feature distributions and outcome frequencies
   - Confirm that the training, validation, and test files have similar treatment and outcome rates
   - Remove `treatment`, `exposure`, `visit`, and `conversion` from the model feature list

3. **Build a random ranking baseline**
   - Assign records a reproducible random score
   - Use this baseline to show what the uplift results might look like without a useful model

4. **Build a response prediction baseline**
   - Train a standard classification model on treatment records to predict the probability of a visit under treatment
   - Rank records by predicted visit probability
   - Compare this ranking with the uplift approaches
   - Explain why predicting likely visitors is different from predicting who may respond because of advertising

5. **Build a T-learner**
   - Train one visit prediction model using treatment records
   - Train a second visit prediction model using control records
   - Score every record with both models
   - Calculate the uplift score as the predicted treatment visit probability minus the predicted control visit probability

6. **Build a transformed-outcome model**
   - Calculate `p` as the treatment rate in the training data
   - Create the target `Z = visit * (treatment - p) / (p * (1 - p))`
   - Do not assume that `p = 0.5` because approximately 85 percent of records are assigned to treatment
   - Train a regression model to predict this transformed target
   - Use the model prediction as an estimated uplift score

7. **Compare the approaches**
   - Use the validation data to compare random ranking, response prediction, the T-learner, and the transformed-outcome model
   - Rank records from highest to lowest score and break tied scores deterministically
   - Divide the ranked records into ten approximately equal audience groups
   - Within each audience group, calculate treatment visit rate minus control visit rate
   - Report treatment and control counts, visit counts, visit rates, uplift, and a 95 percent confidence interval
   - Estimate incremental visits as the number of records in the group multiplied by the estimated uplift
   - Select the most useful and understandable approach before evaluating it on the test data

8. **Complete the final evaluation**
   - Use the test data only after the modeling decisions are complete
   - Create uplift-by-decile and cumulative uplift charts
   - Estimate the incremental visits captured among the highest-ranked audience groups
   - Treat small differences between models as inconclusive when uncertainty intervals substantially overlap
   - Explain whether the results would support targeted advertising, broader targeting, or no targeting recommendation

9. **Interpret the privacy implications**
   - Explain what insights can be reported using anonymous records and aggregate results
   - Identify information that should remain protected inside a real data clean room
   - Explain what cannot be concluded because the features are anonymized and identity matching is outside the project scope
   - Do not present individual uplift scores as privacy-safe audience exports

### Recommended Tools

- **Notebook Environment:** Google Colab
- **Programming Language:** Python
- **Data Processing:** pandas and NumPy
- **Machine Learning:** scikit-learn
- **Charts:** Matplotlib and Seaborn
- **Collaboration and Version Control:** GitHub

Specialized uplift libraries are optional. The required approaches can be implemented with pandas, NumPy, and scikit-learn so the project remains accessible in a free notebook environment.

### Evaluation Metrics

- Overall intention-to-treat uplift calculated as treatment visit rate minus control visit rate
- Uplift by audience decile using the same treatment visit rate minus control visit rate calculation
- Treatment and control record counts, visit counts, and visit rates for every reported group
- A 95 percent confidence interval for overall uplift and each audience decile
- Estimated incremental visits calculated as group size multiplied by estimated uplift
- A cumulative uplift curve created by ranking from highest to lowest model score and accumulating estimated incremental visits
- Optional Qini coefficient or Area Under the Uplift Curve

Standard classification metrics can help evaluate the response prediction models, but they should not be used as the primary measure of uplift model quality.

For a difference-in-proportions confidence interval, students may calculate:

```text
standard error = sqrt((treatment rate * (1 - treatment rate) / treatment count)
                    + (control rate * (1 - control rate) / control count))

95 percent confidence interval = uplift +/- 1.96 * standard error
```

The same definitions must be used for every model so results remain comparable. Individual causal effects are not observed. These metrics evaluate the quality of a ranking through aggregate treatment and control comparisons.
